# 个人知识库 / 笔记助手

一个像 Obsidian 风格的本地知识库工作台，但更简单易用，面向小白用户。

## 产品定位

纯本地运行的桌面端个人知识库，默认完全离线可用；用户可以主动选择把知识库或部分笔记通过联网方式分享出去。

- 默认离线、默认私有、默认不登录、默认不上传
- 分享必须由用户主动触发
- 分享前必须明确告知将分享哪些内容
- UI 风格参考 Obsidian 的本地知识库体验
- 操作像 ima 一样简单，小白用户也能轻松上手

## 快速开始

```bash
npm run electron:dev
```

这会同时启动 Vite 开发服务和 Electron 桌面窗口。

## 数据存储

每篇笔记保存为独立的 `.md` 文件（Obsidian 风格），包含 YAML frontmatter 元数据。

### Vault 目录结构

```text
<系统应用数据目录>/personal-knowledge-notes/vault/
  .vault-meta.json          # 文件夹元数据
  attachments/              # 图片等附件（速记图片自动存入）
  notes/                    # 根目录笔记
    笔记标题.md
  folders/                  # 按文件夹分目录
    <文件夹ID>/
      笔记标题.md
```

### .md 文件格式

```yaml
---
id: "uuid"
title: "标题"
tags: ["标签1", "标签2"]
folderId: "文件夹ID"
createdAt: "2026-05-01T10:00:00.000Z"
updatedAt: "2026-05-01T10:30:00.000Z"
---
Markdown 正文内容
```

Windows 路径：`%APPDATA%/personal-knowledge-notes/vault/`

### 迁移说明

如果从旧版本升级，应用首次启动时会自动将 `notes.json` 迁移为独立 `.md` 文件。迁移后 `notes.json` 会重命名为 `notes.json.migrated`。

Electron 主进程负责读写文件，渲染进程只通过 preload 暴露的 `notesApi` 访问数据。

## AI 配置

AI 功能为可选项，默认关闭；未配置或已禁用时，所有功能自动降级到本地行为，不影响任何本地使用。

### 设置入口

- 点击顶部栏的"设置"按钮，或在命令面板（`Ctrl+K`）中执行"AI 设置"，打开 AI 设置弹窗。
- 可配置项：启用开关、接口地址（baseUrl）、模型、API Key；保存前可点击"测试连接"验证连通性（返回延迟毫秒数）。
- 弹窗中也可以一键"清除 API Key"。

### OpenAI 兼容接口

- 所有 AI 调用由 Electron 主进程转发到 OpenAI 兼容接口，可指向任何兼容服务（官方 OpenAI、自建网关、本地模型服务等）。
- 默认接口地址：`https://api.openai.com/v1`
- 默认模型：`gpt-4o-mini`（图片 OCR 使用视觉模型，语音转写使用 `whisper-1`）
- API Key 保存时留空表示保持已有 Key 不变。

### Key 安全存储

- API Key 由主进程使用 Electron safeStorage 加密后保存在本机配置文件中，不以明文落盘。
- 渲染层只能看到掩码后的 Key（如 `sk-...****`），明文不离开主进程。

### 各 AI 功能用法

- **速记 AI 整理**：速记弹窗中选择整理方式（学习笔记 / 会议纪要 / 项目笔记 / 提取行动项 / 提取知识点），AI 生成结构化 Markdown；调用失败时自动回退本地模板整理。
- **AI 摘要**：编辑器工具栏一键生成当前笔记摘要。
- **AI 标签推荐**：编辑器中根据标题、正文和已有标签推荐新标签，点击即可添加。
- **图片 OCR**：图片速记将选中的图片复制进 vault `attachments/`，笔记中以 `![说明](vault-img://attachments/xxx.png)` 引用显示；可调用视觉模型识别图中文字并插入笔记。
- **语音转写**：语音速记使用 MediaRecorder 录音，音频发送至 whisper-1 转写为文字，可继续 AI 整理后保存为笔记。

### 隐私与降级说明

- 开启 AI 后，相关笔记 / 速记内容会发送到你配置的 API 服务，隐私政策以该服务商为准；介意隐私请保持关闭或使用自建接口。
- AI 未配置或已禁用时，主进程统一返回"AI 未配置或已禁用"：速记整理回退本地模板，语音速记回退为手动粘贴转写文本，摘要 / 标签推荐 / OCR 等入口不展示或给出提示。
- 语义搜索目前仅为占位入口，后续版本提供。

## 安全说明

### 离线运行
- 应用默认完全离线运行
- 不会自动上传任何数据
- 不会自动同步到云端
- 所有笔记数据保存在本机

### 分享安全
- 分享功能需要用户主动触发
- 分享前会显示确认弹窗
- 确认弹窗显示分享范围和内容
- 导出内容不包含本机绝对路径
- 局域网分享默认不开启
- 局域网分享只读，无法修改笔记
- 关闭应用时自动停止局域网分享

### AI 隐私
- AI 功能默认关闭，未配置 API Key 时不产生任何 AI 网络请求
- 开启 AI 后，相关内容仅发送到你配置的接口地址
- API Key 使用 safeStorage 加密存储在本机，明文不离开主进程

## 项目说明

这是一个 Obsidian 风格的本地知识库工作台，但更简单易用。

- 不需要学习复杂概念也能记笔记
- 不需要理解"双链""Vault""图谱"才能使用基础功能
- 创建、编辑、搜索、速记、导出都应该是直觉操作
- 高级能力隐藏在合适位置，不干扰基础写作
