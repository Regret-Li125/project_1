# 个人知识库 / 笔记助手

一个像 Obsidian 风格的本地知识库工作台，但更简单易用，面向小白用户。

## 产品定位

纯本地运行的桌面端个人知识库，默认完全离线可用；用户可以主动选择把知识库或部分笔记通过联网方式分享出去。

- 默认离线、默认私有、默认不登录、默认不上传
- 分享必须由用户主动触发
- 分享前必须明确告知将分享哪些内容
- UI 风格参考 Obsidian 的本地知识库体验
- 操作像 ima 一样简单，小白用户也能轻松上手

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发运行

```bash
npm run electron:dev
```

这会同时启动 Vite 开发服务和 Electron 桌面窗口。

### 只启动渲染层开发服务

```bash
npm run dev
```

### 构建

```bash
npm run build
```

### 打包桌面应用

```bash
npm run electron:package
```

打包产物会输出到 `dist-desktop/` 目录：
- `个人知识库 Setup.exe` - 安装版
- `个人知识库-便携版.exe` - 便携版（双击直接运行）

## 数据存储

桌面端数据保存在：

```text
<系统应用数据目录>/personal-knowledge-notes/notes.json
```

Windows 路径：`%APPDATA%/personal-knowledge-notes/notes.json`

Electron 主进程负责读写文件，渲染进程只通过 preload 暴露的 `notesApi` 访问数据。

## 安全说明

### 离线运行
- 应用默认完全离线运行
- 不会自动上传任何数据
- 不会自动同步到云端
- 所有笔记数据保存在本机

### 分享安全
- 分享功能需要用户主动触发
- 分享前会显示确认弹窗
- 确认弹窗显示分享范围和内容
- 导出内容不包含本机绝对路径
- 局域网分享默认不开启
- 局域网分享只读，无法修改笔记
- 关闭应用时自动停止局域网分享

## 小白用户指南

### 快速记录
1. 打开应用
2. 点击"新建笔记"
3. 输入内容
4. 自动保存

### 快速速记
1. 打开应用
2. 点击"速记"
3. 粘贴一段内容
4. 点击"保存为笔记"

### 快速找回
1. 打开应用
2. 点击搜索框
3. 输入关键词
4. 点击结果

### 导出分享
1. 点击"分享/导出"
2. 选择导出范围
3. 选择导出格式
4. 确认导出

## 项目说明

这是一个 Obsidian 风格的本地知识库工作台，但更简单易用。

- 不需要学习复杂概念也能记笔记
- 不需要理解"双链""Vault""图谱"才能使用基础功能
- 创建、编辑、搜索、速记、导出都应该是直觉操作
- 高级能力隐藏在合适位置，不干扰基础写作

## 技术栈

- Electron - 桌面应用框架
- React - UI 框架
- Vite - 构建工具
- TypeScript - 类型安全
- react-markdown - Markdown 渲染
- archiver - ZIP 压缩
- electron-builder - 应用打包
