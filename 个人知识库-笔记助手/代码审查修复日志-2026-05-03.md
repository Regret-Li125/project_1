# 代码审查修复日志 - 2026-05-03

本日志记录本轮针对桌面端主项目 `note-app/` 的代码审查修复，目标是把项目从“能构建”推进到更稳健的本地桌面产品。

## 已修复问题

### 1. 关闭分享弹窗不会停止局域网分享

- 严重度：P1
- 文件：`note-app/src/components/LocalShareDialog.tsx`
- 问题：用户启动局域网分享后，点击遮罩或“关闭”只隐藏弹窗，没有停止 HTTP 分享服务。
- 修复：新增统一关闭逻辑，关闭弹窗前先调用 `stopSharing()`，再执行 `onClose()`。
- 结果：用户关闭分享弹窗后，不会留下不可见但仍开放的局域网 HTTP 服务。

### 2. 分享服务器路径校验可被前缀绕过

- 严重度：P1
- 文件：`note-app/electron/share/localShareServer.cjs`
- 问题：原逻辑使用 `normalizedPath.startsWith(this.exportPath)` 防目录穿越，可能被相邻目录前缀绕过。
- 修复：导出根目录改为 `path.resolve()` 后的绝对路径；请求路径改为 `path.resolve + path.relative` 校验。
- 结果：`../`、相邻目录前缀等路径穿越请求会被拒绝。

### 3. 关闭应用时可能丢失最后一次编辑

- 严重度：P1
- 文件：
  - `note-app/electron/main.cjs`
  - `note-app/electron/preload.cjs`
  - `note-app/src/App.tsx`
  - `note-app/src/api/lifecycleApi.ts`
- 问题：保存使用 500ms 防抖，用户输入后立即关闭窗口时，最后一次编辑可能还没写入磁盘。
- 修复：主进程关闭窗口前向渲染进程发送关闭请求；渲染进程先刷新待保存内容，再确认关闭。
- 结果：用户输入后立即关闭应用时，最后一次待保存内容会先落盘。

### 4. notes.json 非原子写入且读取失败会静默返回空库

- 严重度：P2
- 文件：`note-app/electron/storage/notesFileStore.cjs`
- 问题：保存直接写 `notes.json`，崩溃或断电可能留下半截 JSON；读取失败后直接返回空库，后续保存可能覆盖原数据。
- 修复：保存时先写临时文件再 `rename`；只有当前主文件可解析时才更新 `.bak`；读取主文件失败时尝试从 `.bak` 恢复。
- 结果：降低崩溃、断电、半截 JSON 导致笔记丢失或被空库覆盖的风险。

### 5. 相同标题导出会互相覆盖

- 严重度：P2
- 文件：`note-app/electron/export/exportService.cjs`
- 问题：目录导出按标题生成文件名，同名笔记会写到同一路径，后一个覆盖前一个。
- 修复：导出时为每篇笔记生成唯一文件名映射；同名文件追加笔记 id 片段或序号；HTML 索引和内部链接统一使用该映射。
- 结果：同名笔记不会在 Markdown/HTML 目录导出或 ZIP 导出中互相覆盖。

### 6. HTML 导出链接未限制 URL 协议

- 严重度：P2
- 文件：`note-app/electron/export/exportService.cjs`
- 问题：Markdown 链接会直接生成 HTML `href`，未过滤 `javascript:`、`file:`、`data:` 等危险协议。
- 修复：新增 URL 白名单过滤，只允许安全的外部协议和受控相对路径。
- 结果：导出的 HTML 和局域网分享页面点击链接时更安全。
